NORTH STAR GOALS
Customer experience
  • When I switch channels, I want the same help and the same answer.
  • When I call in or I'm handed off, I want TELUS to already know me so I don't repeat myself.
  • When I have a problem, I want my provisioning checked first.
  • When I report an issue, I want it fixed the first time, with no truck roll if a phone fix exists.
  • When something breaks, I want it found in seconds, not 30–60 minutes.
  • When my install is done, I want it certified to TELUS standards.
  • When an outage hits, I want it fixed before I call.
  • When equipment is flaky, I want it replaced before it fails.
  • When a release ships, I want it more reliable than the last.
Suggested (industry practice)
  • First-contact resolution and effort tracked per channel
  • Explainable recommendations with human override
  • Privacy by design
  • Real-time freshness
  • Coverage for every device class
  • Root-cause trends feed roadmaps
TELUS enabler
Channels: shared test tools for customers, agents and techs; FieldFrame for agents
Orchestration: Jarvis as one AI; Maestro, Cerebro, Fabric folded in; dispatch guardrails; auto truck roll
Context: unified view with no new data lake; identity stitched; one knowledge base
Telemetry: one vendor-neutral view of line, CPE and in-home
Closed Loop: outage clustering; auto-ticketing; degradation detection
